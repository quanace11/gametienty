# UI

Chỉ đọc `GameState.rules`, nghe `EventBus` và gọi API của `Net`. Không đổi luật.

- `main_menu.gd`: offline (chọn vai), tạo/vào phòng, sảnh chờ, thêm bot
- `hud.gd`: vai, đếm ngược, thời gian, két, cổng, kết quả

Tiếp theo: màn hình kết thúc trận, theo dõi khi bị nhốt (spectate), minimap, điều khiển cảm ứng.
